S3 Upload

Upload files directly to an S3 bucket from your browser

Initialising…
Prerequisite: Your S3 bucket must have a CORS policy allowing requests from this domain. Without it, the upload will fail with a CORS error. Example policy: 
{
  "AllowedOrigins": [
    "https://amirulabu.github.io"
  ],
  "AllowedMethods": [
    "PUT",
    "POST"
  ],
  "AllowedHeaders": [
    "*"
  ]
}
Configure this in your S3 bucket's Permissions → Cross-origin resource sharing (CORS).
